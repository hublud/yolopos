YOLO BITES - Standalone Web App Installs
=========================================

Congratulations! This folder contains your standalone web application for YOLO BITES.

Because we used a special custom single-file bundle system:
1. ALL code, styles, images, and functionality are packed into a SINGLE file: `index.html`.
2. There are no other folders or files needed! Just this one file.
3. You can copy it, share it, or run it completely offline.

How to deploy on your Business PC:
-----------------------------------
1. Copy the `index.html` file in this folder onto a USB flash drive.
2. Plug the USB flash drive into your business computer.
3. Copy the `index.html` file and paste it anywhere on that computer (for example, right on the Desktop).
4. Double-click the `index.html` file!
5. It will immediately open in Google Chrome, Microsoft Edge, or any browser.

Features & Database:
--------------------
- Database: All cashier accounts, products, dynamic prices, custom base64 images, and sales receipts are stored directly in your web browser's secure Local Storage.
- Persistence: Everything you do is saved instantly and remains there even if you close the browser or shut down the computer!
- **IMPORTANT**: To avoid resetting your data, do not run "Clear cookies and site data" or "Reset browser settings" in your browser. 
- Log in with the default Administrator PIN: `1234` to start adding cashiers, setting up drinks, editing prices, and viewing sales history!

Enjoy running your business with YOLO BITES!
